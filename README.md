## Distributed Football Analytics Platform

 
- Built a distributed football analytics system combining an Android app, Java servlet backend, and MongoDB Atlas, enabling real-time retrieval and visualization of top scorers, team stats, and fixtures from the Football-Data.org API.

- Engineered RESTful data flows using OkHttp and Java servlets, handling league-specific API queries and parsing structured JSON responses, while logging each request with metadata into MongoDB for usage analytics.

- Designed and deployed an interactive dashboard using JSP and MongoDB aggregation pipelines to visualize API usage trends, query volumes, and league-level insights through dynamic tables and Google Charts.

- Ensured application robustness through modular activity design in Android, exception-safe JSON parsing, error-handling callbacks, and asynchronous API execution on background threads to support smooth user experience and fault tolerance.
